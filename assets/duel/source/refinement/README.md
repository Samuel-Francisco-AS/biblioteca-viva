# Arte pintada — refinamento F/R3

48 ilustrações novas, criadas pelo tool integrado `image_gen` em 09/11/2026 para a Biblioteca Viva. Quatro atlas de 4×3 painéis, um por tradição e dois companheiros neutros em cada atlas. Prompts completos em `prompts.json`; recortes, dimensões, hashes e procedência em `manifest.json`. Atlas fonte WebP em nível de detalhe alto; runtime usa somente recortes WebP 360×360 (qualidade 86). Extração geométrica exata, sem redesenho por script. Originais PNG gerados preservados fora do repositório; seus hashes constam no manifesto.

Conteúdo visual original de fantasia; sem referências a personagens/franquias, sem assets remotos ou cópia de cartas proprietárias. Arte gerada não é evidência de aprovação artística humana. O autor pode avaliar as 48 representações na coleção/inspeção.

A camada de apresentação resolve os mesmos `artId` para os novos WebP. Catálogo, snapshots, regras, identidades, revisões, backup e os SVG originais da E permanecem intactos. Carta autoral com outro `artId` mantém o fallback SVG anterior.
