# Áudio

Som reforça feedback, mas nunca é a única forma de compreender estado ou confirmar ação. O serviço fica atrás de uma porta da aplicação e degrada para silêncio quando backend ou arquivo estão indisponíveis.

O manifesto ativo contém apenas navegação de página e conclusão de livro. Preferências de volume e mute, inicialização após gesto, pause/resume, visibility e dispose permanecem.

`npm run audio:check` verifica os WAVs determinísticos. Validação auditiva no navegador ou aparelho é humana e permanece aberta.
