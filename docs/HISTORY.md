# História do projeto

A Biblioteca Viva evoluiu de um organizador de leitura para um aplicativo local de registros culturais e pessoais. O checkout atual preserva seis tipos de registro, anotações, etiquetas, favoritos, sessões, estatísticas, preferências e backup.

Em 2026-09-08, o WORLD RESET encerrou integralmente a implementação visual anterior para criar um baseline sem mundo. As decisões, planos e relatos encerrados permanecem como texto em [`history/`](history/README.md); não são instruções operacionais.
