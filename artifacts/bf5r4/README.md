# Capturas da candidata BF-5R4

Chromium desktop automatizado em 390×844. Ambiente vazio e personagens autorados, sem dados pessoais. Seis editores, cinco áreas principais. São evidência de composição e estados reais; não representam aceite artístico ou validação Android/TalkBack. As capturas precedem a última correção do dock: na fonte/APK final ele fica oculto durante todo o editor.

`navigation.json` é um experimento click-to-ready com carga concorrente de gates/SwiftShader, incluindo custo da automação. Não é benchmark utilizável nem demonstra fluidez no Moto G06. Foi preservado para não converter ausência de medida física em alegação de desempenho.

Vetores originais locais: `src/app/ArtifactGlyph.tsx`, `src/app/RealmIntro.tsx`. Nenhum recurso visual externo.
