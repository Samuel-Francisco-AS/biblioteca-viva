BF-3C3 — prévia multiambiente

Colocados / overflow

Navegação

  • Arraste para pan.
  • Use a roda para zoom focal.
  • Use dois dedos para pinch e pan.

Os cinco cômodos são semanticamente neutros; esta distribuição é provisória. Dados são sintéticos e não usam Dexie, consultas, rota Biblioteca ou runtime produtivo. O painel mostra overflow sem criar objetos para ele.
